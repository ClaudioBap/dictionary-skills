# Normalização e desenho

**Resumo:** Normalizar até à 3.ª forma normal por omissão e só desnormalizar com razão medida e documentada.

## Conteúdo

- Normalizar (até à 3ª forma normal) por omissão; eliminar dados repetidos e dependências.
- Desnormalizar só com uma razão de desempenho medida e documentada.

**Para uma skill:** sem dados repetidos por desenho; cada desnormalização tem justificação.
