# Higiene das branches

**Resumo:** Apagar branches fundidas e fechar ou documentar as antigas sem PR.

## Conteúdo

- «Delete branch on merge» ligado; branch sem PR há mais de ~30 dias fecha-se ou documenta-se.
- Um só quadro de temas; evitar dezenas de branches órfãs.

**Para uma skill:** avisar quando há branches fundidas por limpar ou antigas sem PR.
