# Testes

**Resumo:** `pytest` com testes rápidos e isolados, que testam comportamento e incluem casos de erro.

## Conteúdo

- `pytest` com fixtures; padrão arranjar-agir-verificar; testes rápidos e isolados; um motivo de falha por teste.
- Testar comportamento, não implementação; mockar só as fronteiras (rede, BD, tempo).
- Medir cobertura, mas cobertura não é qualidade; incluir casos de erro.

**Para uma skill:** código novo vem com testes do caminho feliz e dos erros.
