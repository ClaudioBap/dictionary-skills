# Atualizações: CI/CD e ferramentas

Novidades com confiança alta ou média (as de média levam «Confiança: media»), organizadas por categoria e da mais recente para a mais antiga. Não alteram o texto das entradas. Cada linha tem o seu registo no [CHANGELOG](../CHANGELOG.md).

## GitHub Actions

- **2026-11-02** em [Segurança do pipeline](seguranca-do-pipeline.md): A partir de 2026-12-02, o GitHub Actions bloqueia por omissão os eventos pull_request_target em todos os repositórios públicos (Free, Team e Enterprise Cloud), salvo se uma política de eventos do Actions os permitir explicitamente; os repositórios privados e internos e o GitHub Enterprise Server não são afetados. Há dois períodos de bloqueio temporário, a 2026-11-09 e a 2026-11-16, das 16:00 às 18:00 UTC, em que as execuções bloqueadas falham. Antes de 9 de novembro, ver em Insights que workflows seriam bloqueados e, para os que precisam do evento, permiti-lo numa política de eventos com indicação do ficheiro do workflow. Fonte: [GitHub Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2). Confiança: alta. Adicionado a 2026-11-04.
- **2026-10-28** em [Segurança do pipeline](seguranca-do-pipeline.md): Os lockfiles de workflows do GitHub Actions estão disponíveis para todos (GA) nos planos Free, Team e Enterprise Cloud. Permitem manter referências legíveis por tag ou branch e executar os commits exatos que ficaram registados em `.github/workflows/actions.lock`, gerado com a extensão `gh actions-lock` e incluindo dependências transitivas. O Dependabot atualiza o lockfile no mesmo pull request, e os administradores podem exigir a adoção com a política «Require lockfile». O lockfile não diz se uma dependência é segura: rever antes de fixar. Fonte: [GitHub Changelog](https://github.blog/changelog/2026-10-28-github-actions-workflow-lockfiles-are-generally-available). Confiança: alta. Adicionado a 2026-11-04.
- **2026-10-28** em [Agentes de IA a par do CI/CD](agentes-de-ia-a-par-do-cicd.md): O GitHub Agentic Workflows está disponível para todos (GA) no github.com (Free, Team e Enterprise). Os workflows são escritos em Markdown em linguagem natural e compilados para YAML do Actions, com o Copilot ou outro agente de código. Proteções incluídas: permissões só de leitura por omissão, contentor isolado atrás de uma firewall de workflows de agentes, validação das saídas e um job de deteção de ameaças que analisa as alterações propostas. O motor por omissão, o Copilot CLI, exige licença do Copilot. Fonte: [GitHub Changelog](https://github.blog/changelog/2026-10-28-github-agentic-workflows-generally-available). Confiança: alta. Adicionado a 2026-11-04.
