# Infraestrutura e migrações no fluxo

**Resumo:** Infraestrutura como código e migrações versionadas fazem parte do deploy.

## Conteúdo

- Infraestrutura como código (versionada, revista como código); ambientes recriáveis a partir do repositório.
- Migrações de base de dados versionadas e aplicadas de forma controlada; um deploy que precisa de esquema novo não está completo sem a migração.

**Para uma skill:** nenhuma mudança de infra ou de esquema é manual e não registada.
