# Atualizações: Nuvem e identidade (AWS, Azure, Microsoft, OVH)

Novidades com confiança alta, organizadas por categoria e da mais recente para a mais antiga. Não alteram o texto das entradas. Cada linha tem o seu registo no [CHANGELOG](../CHANGELOG.md).

## AWS (boletins de segurança)

- **2026-11-03** em [AWS (Amazon Web Services)](aws.md): O Amazon Redshift JDBC Driver anterior à 2.3.0 podia carregar e executar classes arbitrárias a partir de parâmetros do URL JDBC ou de campos do perfil de credenciais (CVE-2026-119084). Atualizar para a 2.3.0; até lá, não construir URLs JDBC nem perfis a partir de dados não confiáveis, ou validá-los contra uma lista permitida. Fonte: [AWS Security Bulletin 2026-168](https://aws.amazon.com/security/security-bulletins/rss/2026-168-aws/). Confiança: alta. Adicionado a 2026-11-04.
- **2026-11-03** em [AWS (Amazon Web Services)](aws.md): O Babelfish for PostgreSQL (versões 1.2 a 1.5, 2.1 a 2.15, 3.1 a 3.12, 4.0 a 4.8 e 5.1 a 5.4) permite a utilizadores autenticados escalar privilégios (CVE-2026-119922). Corrigido nas 4.10, 5.6 e 6.1 ou posteriores; não há alternativa temporária. Fonte: [AWS Security Bulletin 2026-165](https://aws.amazon.com/security/security-bulletins/rss/2026-165-aws/). Confiança: alta. Adicionado a 2026-11-04.
- **2026-11-02** em [AWS (Amazon Web Services)](aws.md): O AWS Serverless MCP Server anterior à v0.2.1 permite, através do nome do projeto, ler e, com escrita ativa, substituir ficheiros JSON fora da pasta de estado de deployment (CVE-2026-116635). Atualizar para a v0.2.1; não há alternativa temporária. Fonte: [AWS Security Bulletin 2026-164](https://aws.amazon.com/security/security-bulletins/rss/2026-164-aws/). Confiança: alta. Adicionado a 2026-11-04.
- **2026-10-30** em [AWS (Amazon Web Services)](aws.md): Uma falha use-after-free no TCP IPv4 do kernel Linux (4.4 ou posterior) permite, com pacotes IPv4 com opções IP, provocar falhas, fuga ou corrupção de memória, com execução remota demonstrada contra listeners MPTCP (CVE-2026-98432). Linux autogerido em EC2 ou Lightsail: atualizar o kernel e reiniciar; nós EKS: AMI v20261031 ou posterior; ECS em EC2: atualizar o kernel ou usar a AMI 20261031. Lambda, EKS Auto Mode e Amazon MQ não exigem ação. Mitigação temporária: desativar o MPTCP (net.mptcp.enabled=0) ou descartar pacotes com opções IP. Fonte: [AWS Security Bulletin 2026-160](https://aws.amazon.com/security/security-bulletins/rss/2026-160-aws/). Confiança: alta. Adicionado a 2026-11-04.
