# Versões e runtime

**Resumo:** Usar uma versão LTS, fixada no projeto, e atualizar antes do fim de suporte.

## Conteúdo

- Usar uma versão LTS do Node.js em produção.
- Fixar a versão no projeto (`engines` no `package.json`, `.nvmrc` ou equivalente) e usar a mesma em dev, CI e produção.
- Planear a atualização antes do fim de suporte da versão em uso.

**Para uma skill:** a versão de Node é LTS, está fixada no repositório e é igual em todos os ambientes.
