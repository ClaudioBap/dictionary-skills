# Testes

**Resumo:** JUnit 5, AssertJ e Mockito, com testes rápidos que testam comportamento.

## Conteúdo

- JUnit 5, AssertJ para asserções legíveis, Mockito para as fronteiras; arranjar-agir-verificar.
- Testes rápidos e independentes; testar comportamento, não detalhes internos.

**Para uma skill:** código novo vem com testes de caminho feliz e de erro.
