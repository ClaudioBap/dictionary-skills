# Design OO e SOLID

**Resumo:** Princípios SOLID, composição e injeção de dependências.

## Conteúdo

- Responsabilidade única, aberto/fechado, substituição de Liskov, segregação de interfaces, inversão de dependências.
- Composição em vez de herança; injeção de dependências; encapsular estado.

**Para uma skill:** dependências injetadas, não criadas lá dentro; classes com um motivo para mudar.
