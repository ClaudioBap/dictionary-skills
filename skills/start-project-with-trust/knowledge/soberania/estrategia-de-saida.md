# Estratégia de saída

**Resumo:** O sistema funciona sem um fornecedor específico, com exportação aberta e restauro provado.

## Conteúdo

- O sistema tem de poder funcionar sem um fornecedor específico; evitar amarras que tornem a saída impossível.
- Exportação completa em formatos abertos testada no CI; backups cifrados com chave do cliente, fora do fornecedor, com restauro ensaiado.

**Para uma skill:** toda a fonte de dados externa tem exportação aberta e restauro provado antes de produção.
