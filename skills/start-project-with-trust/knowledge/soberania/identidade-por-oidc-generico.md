# Identidade por OIDC genérico

**Resumo:** Falar OIDC padrão para trocar de IdP ser configuração e não código.

## Conteúdo

- Falar OIDC padrão, não a biblioteca de um fornecedor, para trocar de IdP ser configuração e não código.
- Suportar IdP institucionais e federações (Keycloak, eduGAIN/RCTSaai, etc.).

**Para uma skill:** o login usa OIDC padrão, sem amarra a um fornecedor.
