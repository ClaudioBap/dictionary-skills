# Um só cofre de segredos soberano

**Resumo:** Um só secret manager europeu ou self-hosted em todos os ambientes.

## Conteúdo

- Um secret manager europeu ou self-hosted (OKMS, OpenBao/Vault) em todos os ambientes, com a mesma autenticação de máquina.
- Evitar espalhar segredos por vários fornecedores e caminhos de código.

**Para uma skill:** um só backend de segredos, na jurisdição escolhida.
