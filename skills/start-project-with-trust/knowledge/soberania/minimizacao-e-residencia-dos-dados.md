# Minimização e residência dos dados

**Resumo:** Recolher o mínimo e saber a região onde cada armazém de dados vive.

## Conteúdo

- Política de retenção e apagamento escrita; DPIA quando há dados sensíveis.

**Para uma skill:** cada campo pessoal tem justificação, retenção e residência conhecidas.
