# Testes de carga e resiliência

**Resumo:** Testar carga e resiliência (chaos) para saber onde o sistema parte e se recupera.

## Conteúdo

- Teste de carga (k6, Gatling, Locust) para saber onde parte e a que custo escala.
- Testes de resiliência/chaos: matar instâncias, cortar rede, ver se recupera.

**Para uma skill:** o sistema foi testado ao ponto de rutura e sabe-se o seu limite.
