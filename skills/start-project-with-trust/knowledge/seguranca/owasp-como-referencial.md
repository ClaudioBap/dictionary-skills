# OWASP como referencial

**Resumo:** Usar o OWASP Top 10 como checklist, o ASVS como nível-alvo e as Cheat Sheets como receitas.

## Conteúdo

- **OWASP Top 10:** a checklist das falhas web mais comuns; rever cada uma contra o projeto.
- **OWASP ASVS:** níveis de verificação de segurança, do básico ao rigoroso, como critério de cobertura.
- **OWASP Cheat Sheets:** receitas concretas por tema (sessões, JWT, uploads, etc.).

**Para uma skill:** o projeto é avaliado contra o OWASP Top 10 e escolhe um nível ASVS como alvo.
