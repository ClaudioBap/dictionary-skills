# Dados de teste sintéticos e minimização

**Resumo:** Nunca copiar dados pessoais reais para dev; gerar dados sintéticos e recolher o mínimo, com retenção.

## Conteúdo

- Nunca copiar dados pessoais reais para dev; gerar dados sintéticos desde o início.
- Se um ambiente de teste precisar de dados realistas, pseudonimizar ao copiar.
- Recolher o mínimo de dados pessoais, com prazo de retenção e apagamento.

**Para uma skill:** nenhum dado pessoal real em dev; cada campo pessoal tem justificação e retenção.
