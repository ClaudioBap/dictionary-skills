# Dados estruturados e partilha

**Resumo:** Dados estruturados para os motores e cartões de partilha para os links.

## Conteúdo

- Dados estruturados (schema.org/JSON-LD) para os motores entenderem o conteúdo.
- Open Graph e Twitter Cards para o link ficar bonito quando partilhado.

**Para uma skill:** o conteúdo relevante tem dados estruturados e cartões de partilha.
