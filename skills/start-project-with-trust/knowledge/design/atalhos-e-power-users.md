# Atalhos e power users

**Resumo:** Atalhos de teclado e paleta de comandos para quem usa muito, sem prejudicar os ocasionais.

## Conteúdo

- Teclado para quem usa muito: atalhos nas ações frequentes, foco gerido, formulários submetíveis por teclado.
- Uma paleta de comandos (command palette) dá acesso rápido sem decorar menus; manter o básico simples para os ocasionais.

**Para uma skill:** as ações frequentes têm atalho de teclado, sem prejudicar quem usa só o rato.
