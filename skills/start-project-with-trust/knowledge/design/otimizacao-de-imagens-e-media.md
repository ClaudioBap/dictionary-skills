# Otimização de imagens e media

**Resumo:** Formatos modernos, tamanhos responsivos, dimensões fixas e lazy loading do que está abaixo da dobra.

## Conteúdo

- Formatos modernos (AVIF/WebP), tamanhos responsivos (`srcset`), dimensões fixas para não saltar o layout.
- Lazy loading do que está abaixo da dobra; vídeos comprimidos e carregados sob pedido.

**Para uma skill:** nenhuma imagem é servida maior do que aparece; media pesada carrega tarde.
