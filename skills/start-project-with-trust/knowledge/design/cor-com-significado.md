# Cor com significado

**Resumo:** Cores semânticas consistentes e nunca só a cor para dar informação.

## Conteúdo

- Cores semânticas consistentes (sucesso, aviso, erro, informação) com o mesmo sentido em todo o lado.
- Nunca usar só a cor para dar informação: juntar ícone, texto ou forma (daltonismo e contexto).
- Contraste suficiente; a cor realça, não carrega sozinha a mensagem.

**Para uma skill:** nenhuma informação depende só da cor; os estados têm ícone ou texto.
