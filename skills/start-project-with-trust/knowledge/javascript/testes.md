# Testes

**Resumo:** Testes unitários rápidos, testes de componentes pelo comportamento e alguns ponta-a-ponta.

## Conteúdo

- Unitários com Vitest ou Jest; componentes com Testing Library, a testar o que o utilizador vê e faz, não a implementação.
- Ponta-a-ponta com Playwright ou Cypress, poucos e nos fluxos críticos.
- Mockar só as fronteiras (rede, tempo); testes determinísticos.

**Para uma skill:** código novo vem com testes do caminho feliz e dos erros; os fluxos críticos têm teste ponta-a-ponta.
