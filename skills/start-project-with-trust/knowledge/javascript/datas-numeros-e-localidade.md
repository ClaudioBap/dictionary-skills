# Datas, números e localidade

**Resumo:** Formatar com a API `Intl`, guardar e transmitir datas em UTC (ISO 8601).

## Conteúdo

- Formatar datas, números e moeda com `Intl.DateTimeFormat` e `Intl.NumberFormat`, pela localidade do utilizador.
- Guardar e transmitir datas em UTC, no formato ISO 8601; converter para a hora local só na apresentação.
- Não concatenar frases traduzidas; usar mensagens com parâmetros.

**Para uma skill:** nenhuma data ou número é formatado à mão; as datas circulam em UTC.
