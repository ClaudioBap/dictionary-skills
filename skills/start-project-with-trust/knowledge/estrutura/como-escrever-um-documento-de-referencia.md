# Como escrever um documento de referência

**Resumo:** Cada documento diz para quem é, o que cobre e quando foi verificado, com um tema por documento.

## Conteúdo

- Cabeçalho que diz «para quem» e «o que cobre», e um «estado verificado a ».
- Um tema por documento; links em vez de repetir; tabelas para o que é consulta.
- Explicar o mecanismo real, não o que se gostaria que fosse; dizer o que não está feito.

**Para uma skill:** cada documento diz para quem é, o que cobre e quando foi verificado.
