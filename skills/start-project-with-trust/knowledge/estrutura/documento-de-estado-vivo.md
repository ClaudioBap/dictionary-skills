# Documento de estado vivo

**Resumo:** Um documento que diz onde estamos, atualizado a cada entrega.

## Conteúdo

- Um documento que diz o que está em produção, o que falta correr ou fazer e os pendentes; atualiza-se a cada entrega.
- Fica fora do travão da referência, porque muda sempre; um pendente fechado sai, não se risca.
- É onde se olha para saber «onde estamos».

**Para uma skill:** existe um documento de estado atualizado a cada entrega.
