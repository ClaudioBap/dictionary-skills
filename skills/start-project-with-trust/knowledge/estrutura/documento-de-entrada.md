# Documento de entrada (leia primeiro)

**Resumo:** Um só ponto de entrada, curto e atual, que é o mapa do projeto.

## Conteúdo

- Um só ponto de entrada (`README`/índice) que diz o que é o projeto, o vocabulário e onde está cada coisa.
- Liga para os documentos de tema; é o mapa, não o conteúdo todo; curto e atual.

**Para uma skill:** existe um índice de entrada e aponta para tudo o que importa.
