# MCP (Model Context Protocol)

**Resumo:** Protocolo aberto para ligar o modelo a fontes e ferramentas externas de forma padronizada.

## Conteúdo

- Protocolo aberto para ligar o modelo a fontes e ferramentas externas de forma padronizada; um servidor MCP expõe recursos e ações que o modelo usa.
- Reutilizável entre projetos e modelos; evita integrações à medida para cada fonte.

**Para uma skill:** integrações padronizadas usam MCP em vez de colar cada fonte à mão.
