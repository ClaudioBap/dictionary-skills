# Escolher a superfície (do simples ao agente)

**Resumo:** Começar pelo mais simples que resolve (chamada, workflow, agente) e só subir de nível com justificação.

## Conteúdo

- Começar pelo mais simples que resolve: **uma chamada** (classificar, resumir, extrair, responder) → **workflow** (vários passos que tu orquestras, com tool use) → **agente** (exploração aberta guiada pelo modelo).
- Só construir agente se a tarefa for multi-passo e difícil de especificar, o valor justificar o custo, o Claude for capaz, e o erro for recuperável.

**Para uma skill:** justificar a subida de tier; não usar agente onde uma chamada ou um workflow chegam.
