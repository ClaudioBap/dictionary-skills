# Claude Code e Claude Agent SDK

**Resumo:** O Claude Code como agente de código configurável e o Agent SDK que o empacota como biblioteca.

## Conteúdo

- **Claude Code** é o agente de código no terminal/IDE; configura-se por um ficheiro de regras (ex.: `CLAUDE.md`), hooks, comandos e subagentes.
- **Claude Agent SDK** empacota esse harness como biblioteca, para construíres agentes de código e ficheiros na tua infraestrutura.

**Para uma skill:** um agente de código traz regras, hooks e permissões versionados, não configuração solta.
