# Cursos gratuitos da Anthropic Academy

**Resumo:** Os cursos gratuitos da Anthropic Academy, de base e para construir, com certificado de conclusão.

## Conteúdo

- Base: Claude 101, AI Fluency (Framework & Foundations, com variantes por público), Claude Platform 101.
- Construir: Building with the Claude API, Introduction to Model Context Protocol, Model Context Protocol: Advanced Topics, Claude Code 101, Claude Code in Action, Introduction to subagents, Introduction to agent skills.
- Dão certificado de conclusão (não é a certificação com proctor); confirmar a lista atual em anthropic.skilljar.com.

**Para uma skill:** antes de construir com IA, cobrir API, MCP, Claude Code, subagentes e agent skills.
