# Pesquisa (OpenSearch, Meilisearch)

**Resumo:** Um motor de pesquisa próprio para texto, em vez de `LIKE` na base.

## Conteúdo

- Motor de pesquisa de texto: procura rápida, relevância, filtros e facetas que a base relacional não faz bem.
- **OpenSearch/Elasticsearch:** potente, também serve para logs. **Meilisearch/Typesense:** leves, pesquisa instantânea para sites.

**Para uma skill:** pesquisa de texto rica usa um motor próprio, não `LIKE` na base.
