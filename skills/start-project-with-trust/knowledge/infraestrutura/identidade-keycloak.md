# Identidade (Keycloak)

**Resumo:** Servidor de identidade aberto com SSO, OIDC/SAML e MFA, alternativa soberana.

## Conteúdo

- Servidor de identidade aberto: SSO, OIDC/SAML, MFA, gestão de utilizadores e papéis, federação com outros IdP.
- Alternativa soberana a um fornecedor de identidade de nuvem; fala OIDC padrão.

**Para uma skill:** o login usa um servidor OIDC (próprio ou institucional), não autenticação caseira.
