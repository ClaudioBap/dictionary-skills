# Pattern matching e features modernas

**Resumo:** Usar as features modernas para clareza, não por moda.

## Conteúdo

- `switch` expressions, pattern matching, `nameof`, interpolação de strings, expressões de corpo único quando ajudam a ler.
- Usar as features para clareza, não por moda; manter consistência no projeto.

**Para uma skill:** usar a feature que torna o código mais claro, não a mais nova.
