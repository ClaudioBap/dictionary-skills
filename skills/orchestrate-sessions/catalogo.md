# Catálogo de mini skills

Cada sessão de trabalho recebe uma mini skill. O conhecimento fica todo em `../start-project-with-trust/knowledge/`; as mini skills só trazem o processo.

Enquanto uma mini skill estiver `por criar`, o briefing manda a sessão ler diretamente as secções indicadas, começando pelo `README.md` de cada uma.

| Mini skill | Para quê | Secções de `knowledge/` | Estado |
|---|---|---|---|
| `design-ux` | Interface, acessibilidade, formulários, SEO | `design/`, `seo/` | instalada |
| `design-3d-motion` | 3D, WebGL, animação e movimento | `3d-webgl/` | instalada |
| `seguranca` | Auditar e proteger um site ou aplicação | `seguranca/`, `privacidade/`, `acesso-remoto/`, e o script `../start-project-with-trust/scripts/verificar-publicacao.mjs` | instalada |
| `performance-verifier` | Velocidade e custo do site, custo e latência da IA | `custo/`, `ia/otimizacao-de-custo-da-ia.md`, `ia/escolher-o-modelo-claude.md`, `design/desempenho-web-core-web-vitals.md`, `design/orcamento-de-desempenho.md`, `base-de-dados/desempenho-de-queries.md`, `3d-webgl/orcamento-de-desempenho-3d.md` | instalada |
| `backend-dados` | API, base de dados, fiabilidade | `api/`, `base-de-dados/`, `fiabilidade/` | instalada |
| `infra-deploy` | CI/CD, contentores, alojamento, publicação | `cicd/`, `docker/`, `infraestrutura/`, `nuvem/`, `publicacao/`, `soberania/` | instalada |
| `boas-praticas-codigo` | Código numa das linguagens da base (lê só a pasta da linguagem do projeto) | `python/`, `java/`, `csharp/`, `javascript/`, `node/` | instalada |
| `ia-aplicada` | Qualquer trabalho com IA: APIs, RAG, agentes, modelo próprio, modelos abertos, voz, segurança, operação | `ia/` e as suas subpastas (a skill pergunta qual) | instalada |
| `gravacao-video` | Vídeos de demonstração, teasers e explicações de um site, com voz | `ia/multimodal/` | instalada |
| `produtizar` | Transformar o que foi feito para um caso num núcleo reutilizável com adaptadores e configuração, ou num modelo de projeto | `produto/` | instalada |
| `operar` | Deixar uma plataforma pronta para quem a vai operar: monitorização, runbooks, cópias de segurança, incidentes | `fiabilidade/`, `docker/`, `cicd/` | instalada |

Ficam na `start-project-with-trust`, porque servem para decidir e não para executar: `plataformas/`, `governacao/`, `estrutura/`.

Quando uma mini skill for criada, muda o estado para `instalada` nesta tabela.
