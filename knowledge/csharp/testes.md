# Testes

**Resumo:** xUnit ou NUnit com testes rápidos e isolados que testam comportamento.

## Conteúdo

- xUnit ou NUnit, FluentAssertions, Moq/NSubstitute; arranjar-agir-verificar.
- Testes rápidos, isolados, a testar comportamento; mockar só as fronteiras.

**Para uma skill:** código novo vem com testes de caminho feliz e de erro.

## Fontes oficiais

*Ligações externas que apoiam esta entrada, consultadas a 2026-11-04. Não alteram o texto acima.*

- [Best practices for writing unit tests](https://learn.microsoft.com/en-us/dotnet/core/testing/unit-testing-best-practices) — Arrange-Act-Assert; testes isolados; stubs e mocks
- [xUnit.net](https://xunit.net/) — framework de testes .NET (v3 atual)
- [Fluent Assertions](https://fluentassertions.com/) — asserções fluentes
