# Inventário de dependências por jurisdição

**Resumo:** Uma tabela de cada dependência externa com função, jurisdição, dados que lá passam e decisão.

## Conteúdo

- Uma tabela com cada dependência externa: função, jurisdição, classe de dados que lá passa, e decisão de quem.
- Distinguir os planos (código, CI, identidade, segredos, dados, email, execução) e onde cada um vive.

**Para uma skill:** nenhuma integração externa entra sem uma linha nesta tabela.
