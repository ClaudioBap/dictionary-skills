# Offline, PWA e melhoria progressiva

**Resumo:** A página base funciona sem JavaScript pesado e, quando faz sentido, como PWA com rede fraca ou offline.

## Conteúdo

- A página base funciona sem JavaScript pesado; a experiência melhora onde o browser aguenta.
- PWA (service worker, manifesto) para funcionar com rede fraca ou offline, quando faz sentido.

**Para uma skill:** a funcionalidade essencial funciona com rede fraca e sem depender de tudo carregar.
