# Cor com significado

**Resumo:** Cores semânticas consistentes e nunca só a cor para dar informação.

## Conteúdo

- Cores semânticas consistentes (sucesso, aviso, erro, informação) com o mesmo sentido em todo o lado.
- Nunca usar só a cor para dar informação: juntar ícone, texto ou forma (daltonismo e contexto).
- Contraste suficiente; a cor realça, não carrega sozinha a mensagem.

**Para uma skill:** nenhuma informação depende só da cor; os estados têm ícone ou texto.

## Fontes oficiais

*Ligações externas que apoiam esta entrada, consultadas a 2026-11-04. Não alteram o texto acima.*

- [WCAG 2.2 – 1.4.1 Use of Color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html) — A cor não pode ser o único meio visual de informação
- [WCAG 2.2 – 1.4.3 Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) — Contraste mínimo de 4,5:1 para texto
