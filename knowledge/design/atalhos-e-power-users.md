# Atalhos e power users

**Resumo:** Atalhos de teclado e paleta de comandos para quem usa muito, sem prejudicar os ocasionais.

## Conteúdo

- Teclado para quem usa muito: atalhos nas ações frequentes, foco gerido, formulários submetíveis por teclado.
- Uma paleta de comandos (command palette) dá acesso rápido sem decorar menus; manter o básico simples para os ocasionais.

**Para uma skill:** as ações frequentes têm atalho de teclado, sem prejudicar quem usa só o rato.

## Fontes oficiais

*Ligações externas que apoiam esta entrada, consultadas a 2026-11-04. Não alteram o texto acima.*

- [NN/g – Accelerators](https://www.nngroup.com/articles/ui-accelerators/) — Atalhos aceleram peritos sem prejudicar novatos
- [WCAG 2.2 – 2.1.4 Character Key Shortcuts](https://www.w3.org/WAI/WCAG22/Understanding/character-key-shortcuts.html) — Atalhos de uma tecla têm de poder ser desligados/remapeados

> **Nota (fonte oficial):** WCAG 2.1.4 (nível A) impõe que atalhos de uma só tecla imprimível possam ser desativados, remapeados ou só ativos com foco; a entrada não o refere.
