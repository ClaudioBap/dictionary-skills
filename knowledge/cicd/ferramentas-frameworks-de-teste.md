# Ferramentas: frameworks de teste

**Resumo:** Frameworks de teste por linguagem e para ponta-a-ponta web.

## Conteúdo

- **Python:** `pytest`. **Java:** `JUnit 5` + `AssertJ` + `Mockito`. **C#:** `xUnit` / `NUnit` + `FluentAssertions` + `Moq` / `NSubstitute`. **Ponta-a-ponta web:** `Playwright` ou `Cypress`.

**Para uma skill:** existe framework de teste por camada e os testes correm no pipeline.

## Fontes oficiais

*Ligações externas que apoiam esta entrada, consultadas a 2026-11-04. Não alteram o texto acima.*

- [pytest](https://docs.pytest.org/en/stable/) — Framework de testes Python, de unitários a funcionais
- [JUnit](https://junit.org/junit5/) — Framework de testes para Java e JVM
- [Playwright](https://playwright.dev/docs/intro) — Framework de testes ponta-a-ponta web, com workflow de CI

> **Nota (fonte oficial):** O site do JUnit indica que a geração atual é o JUnit 6 (requer Java 17+); o PDF refere JUnit 5.
