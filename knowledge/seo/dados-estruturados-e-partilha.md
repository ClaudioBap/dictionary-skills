# Dados estruturados e partilha

**Resumo:** Dados estruturados para os motores e cartões de partilha para os links.

## Conteúdo

- Dados estruturados (schema.org/JSON-LD) para os motores entenderem o conteúdo.
- Open Graph e Twitter Cards para o link ficar bonito quando partilhado.
- Formato: a Google recomenda JSON-LD quando o site o permite e aceita também Microdata e RDFa, desde que o markup seja válido. Para dar um resultado enriquecido, o objeto tem de ter todas as propriedades obrigatórias dessa funcionalidade. Valida-se com o Rich Results Test durante o desenvolvimento e, depois de publicar, acompanham-se os relatórios de estado dos resultados enriquecidos, porque o markup pode partir com o template ou com a forma como a página é servida. Fonte: [Google: Intro to structured data (2025-12-10)](https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data)

**Para uma skill:** o conteúdo relevante tem dados estruturados e cartões de partilha. A prova é o Rich Results Test sem erros nas páginas com dados estruturados.
