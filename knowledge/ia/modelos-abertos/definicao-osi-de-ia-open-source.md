# Definição OSI de IA open source

**Resumo:** Para a OSI, um sistema de IA só é open source se publicar informação sobre os dados de treino, o código de treino e execução, e os parâmetros; pesos abertos sozinhos não chegam.

## Conteúdo

- A Open Source AI Definition está na versão 1.0. Fonte: [Open Source AI Definition](https://opensource.org/ai/open-source-ai-definition)
- A forma preferida para modificar o sistema tem de incluir três coisas:
  - «Sufficiently detailed information about the data used to train the system»;
  - «The complete source code used to train and run the system»;
  - «The model parameters, such as weights or other configuration settings».

  Fonte: a mesma página.

**Para uma skill:** quando um plano diz que um modelo é «open source», confirma as três condições da definição da OSI; se faltar alguma, chama-lhe «modelo com pesos abertos».
