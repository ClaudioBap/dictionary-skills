# Atualizações: Construir com IA

Novidades com confiança alta ou média (as de média levam «Confiança: media»), organizadas por categoria e da mais recente para a mais antiga. Não alteram o texto das entradas. Cada linha tem o seu registo no [CHANGELOG](../CHANGELOG.md).

## Claude (Anthropic)

- **2026-11-12** em [Agentes: as quatro formas de construir](agentes-as-quatro-formas-de-construir.md): Os Claude Managed Agents passam a poder correr por inteiro na infraestrutura de quem os usa (self-hosted), incluindo os agentes, as sessões e o histórico. Os pedidos ao modelo seguem para o fornecedor escolhido, que por omissão é a Anthropic. O acesso pede-se à equipa de conta da Anthropic. Fonte: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview). Confiança: alta. Adicionado a 2026-11-14.
- **2026-11-09** em [Escolher o modelo Claude](escolher-o-modelo-claude.md): Lançamento do Claude Fable 5.2 (`claude-fable-5-2`) e do Claude Mythos 5.2 (`claude-mythos-5-2`, só para organizações verificadas), ambos com pensamento adaptativo sempre ligado, contexto de 1M e saída até 128K. O fast mode está disponível no Fable 5.2 com `"speed": "fast"`, sem cabeçalho beta, a $16 por milhão de tokens de entrada e $80 de saída. Os dois modelos exigem o toolset `computer_toolset_20260801` para computer use e têm retenção de dados de 30 dias. A entrada foi reescrita nesta data (ver «Histórico»). Fonte: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview). Confiança: alta. Adicionado a 2026-11-10.
- **2026-11-03**: O texto gerado pelo Mythos 5, pelo Opus 4.7 e pelo Sonnet 4.6 passa a ter a marca de água de texto da Anthropic; no Sonnet 4.6, saídas com parâmetros de amostragem fora do padrão podem não a ter. Fonte: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview). Confiança: alta. Adicionado a 2026-11-10.
- **2026-10-30** em [Escolher o modelo Claude](escolher-o-modelo-claude.md): O fast mode do Claude Opus 4.8 foi descontinuado e é removido a 2026-11-30. Depois dessa data, os pedidos a `claude-opus-4-8` com `speed: "fast"` devolvem erro. Para continuar a usar o fast mode, a migração indicada é para o Claude Opus 5.5. Fonte: [Claude Platform: fast mode](https://platform.claude.com/docs/en/build-with-claude/fast-mode). Confiança: alta. Adicionado a 2026-11-04.
- **2026-10-29** em [Otimização de custo da IA](otimizacao-de-custo-da-ia.md): A Usage and Cost Analytics API está em beta (cabeçalho `analytics-usage-cost-2026-08-24`), com os endpoints `/v1/organizations/analytics/usage` (tokens e pedidos) e `/v1/organizations/analytics/cost` (custo em USD). A Usage and Cost API e os endpoints `usage_report`, `cost_report`, `user_usage_report` e `user_cost_report` da Claude Enterprise Analytics API passam a legacy, mas continuam suportados. Fonte: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview). Confiança: alta. Adicionado a 2026-11-04.
- **2026-10-28** em [Gestão de contexto e fiabilidade](gestao-de-contexto-e-fiabilidade.md): O tamanho máximo do pedido na Messages API e na Token Counting API passou de 32 MB para 128 MB, só na Claude API de primeira parte. Nas plataformas parceiras os limites são outros: 20 MB no Amazon Bedrock, 30 MB no Google Cloud gerido pela Google e 32 MB na Claude Platform on AWS, nos Claude Models on Google Cloud geridos pela Anthropic e no Microsoft Foundry. Acima do limite, a API devolve o erro 413 `request_too_large`. Fonte: [Claude Platform: API overview](https://platform.claude.com/docs/en/api/overview). Confiança: alta. Adicionado a 2026-11-04.

## Mistral

- **2026-10-31**: A Mistral descontinuou nesta data o Mistral Medium 3.5 (`mistral-medium-3-5`), o Mistral Large 3 (`mistral-large-2512`), o Voxtral TTS (`voxtral-mini-tts-2603`), o Voxtral Mini Transcribe 2 (`voxtral-mini-2602`) e o Voxtral Mini Transcribe Realtime (`voxtral-mini-transcribe-realtime-2602`). Os cinco são retirados da API a 2027-04-30. Fonte: [Mistral: modelos](https://docs.mistral.ai/getting-started/models/). Confiança: alta. Adicionado a 2026-11-14.

Fonte: [MCP: especificação](https://modelcontextprotocol.io/specification/latest). Confiança: media. Adicionado a 2026-11-16.
