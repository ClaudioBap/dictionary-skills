## Claude (Anthropic)

- **2026-11-23** em [Escolher o modelo Claude](escolher-o-modelo-claude.md): O Claude Opus 4.5 (`claude-opus-4-5-20251101` e `claude-opus-4-5`) está descontinuado e é retirado da Claude API a 2027-01-22; a migração indicada é para o Claude Opus 5.5. Fonte: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview). Confiança: alta. Adicionado a 2026-11-26.
- **2026-11-12** em [Agentes: as quatro formas de construir](agentes-as-quatro-formas-de-construir.md): Os Claude Managed Agents passam a poder correr por inteiro na infraestrutura de quem os usa (self-hosted), incluindo os agentes, as sessões e o histórico. Os pedidos ao modelo seguem para o fornecedor escolhido, que por omissão é a Anthropic. O acesso pede-se à equipa de conta da Anthropic. Fonte: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview). Confiança: alta. Adicionado a 2026-11-14.
- **2026-11-09** em [Escolher o modelo Claude](escolher-o-modelo-claude.md): Lançamento do Claude Fable 5.2 (`claude-fable-5-2`) e do Claude Mythos 5.2 (`claude-mythos-5-2`, só para organizações verificadas), ambos com pensamento adaptativo sempre ligado, contexto de 1M e saída até 128K. O fast mode está disponível no Fable 5.2 com `"speed": "fast"`, sem cabeçalho beta, a $16 por milhão de tokens de entrada e $80 de saída. Os dois modelos exigem o toolset `computer_toolset_20260801` para computer use e têm retenção de dados de 30 dias. A entrada foi reescrita nesta data (ver «Histórico»). Fonte: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview). Confiança: alta. Adicionado a 2026-11-10.
- **2026-11-09** em [Pensar (thinking) e esforço (effort)](pensar-e-esforco.md): A verificação de prefixo passou a ser imposta a todas as contas: editar o `system`, as `tools` ou uma mensagem anterior e devolver depois um bloco de pensamento dá erro 400. Fonte: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview). Confiança: alta. Adicionado a 2026-11-26.
- **2026-11-06** em [Memória de agentes (Mem0, Graphiti, A-MEM, Letta, memory tool)](rag/memoria-de-agentes.md): A Anthropic recomenda dizer ao modelo para que serve a memória em vez de lhe dar regras rígidas de uso (com regras como «registar só as falhas», os modelos mais fortes perdem parte do ganho), mandar os modelos mais antigos ler a memória, manter pequena a camada injetada em cada sessão (o Claude Code carrega só as primeiras 200 linhas ou 25 KB do `MEMORY.md`), ter uma página por entidade e corrigir as notas erradas com uma revisão offline dos registos («dreaming»). Os números do artigo são dos autores, em testes escolhidos por eles. Fonte: [Anthropic: The components of agent memory](https://www.anthropic.com/research/components-of-agent-memory). Confiança: alta. Adicionado a 2026-11-26.
- **2026-11-03**: O texto gerado pelo Mythos 5, pelo Opus 4.7 e pelo Sonnet 4.6 passa a ter a marca de água de texto da Anthropic; no Sonnet 4.6, saídas com parâmetros de amostragem fora do padrão podem não a ter. Fonte: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview). Confiança: alta. Adicionado a 2026-11-10.
- **2026-10-30** em [Escolher o modelo Claude](escolher-o-modelo-claude.md): O fast mode do Claude Opus 4.8 foi descontinuado e é removido a 2026-11-30. Depois dessa data, os pedidos a `claude-opus-4-8` com `speed: "fast"` devolvem erro. Para continuar a usar o fast mode, a migração indicada é para o Claude Opus 5.5. Fonte: [Claude Platform: fast mode](https://platform.claude.com/docs/en/build-with-claude/fast-mode). Confiança: alta. Adicionado a 2026-11-04.
- **2026-10-29** em [Otimização de custo da IA](otimizacao-de-custo-da-ia.md): A Usage and Cost Analytics API está em beta (cabeçalho `analytics-usage-cost-2026-08-24`), com os endpoints `/v1/organizations/analytics/usage` (tokens e pedidos) e `/v1/organizations/analytics/cost` (custo em USD). Fonte: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview). Confiança: alta. Adicionado a 2026-11-04.
- **2026-10-28** em [Gestão de contexto e fiabilidade](gestao-de-contexto-e-fiabilidade.md): O tamanho máximo do pedido na Messages API e na Token Counting API passou de 32 MB para 128 MB, só na Claude API de primeira parte. Acima do limite, a API devolve o erro 413 `request_too_large`. Fonte: [Claude Platform: API overview](https://platform.claude.com/docs/en/api/overview). Confiança: alta. Adicionado a 2026-11-04.

## Model Context Protocol (MCP)

- **2026-07-28** em [MCP (Model Context Protocol)](mcp-model-context-protocol.md): O que mudou na especificação 2026-07-28 face à 2025-11-25: o protocolo deixa de ter sessões (sai o cabeçalho `Mcp-Session-Id`, e o estado entre chamadas passa por «handles» do servidor dados como argumentos das ferramentas) e handshake (sai o `initialize`, e cada pedido leva a versão do protocolo e as capacidades do cliente em `_meta`), e os servidores têm de implementar o novo `server/discover`. As tarefas passam a uma extensão oficial (`io.modelcontextprotocol/tasks`), o servidor pede dados ao cliente devolvendo `InputRequiredResult` em vez de enviar pedidos próprios, saem o `ping`, o `logging/setLevel` e a retoma de streams SSE, e os POST HTTP passam a levar os cabeçalhos `Mcp-Method` e `Mcp-Name`. Ficam descontinuados o Roots, o Sampling, o Logging, o transporte HTTP+SSE (a migrar para Streamable HTTP) e o registo dinâmico de clientes (RFC 7591), a favor dos Client ID Metadata Documents; a janela de descontinuação é de pelo menos 12 meses. Fonte: [MCP: Key Changes (2026-07-28)](https://modelcontextprotocol.io/specification/2026-07-28/changelog). Confiança: alta. Adicionado a 2026-11-26.
- **2026-07-28** em [MCP (Model Context Protocol)](mcp-model-context-protocol.md): A versão atual da especificação MCP é a 2026-07-28; o que mudou face à anterior ainda não foi lido. Fonte: [MCP: especificação](https://modelcontextprotocol.io/specification/latest). Confiança: media. Adicionado a 2026-11-16.

## RAG e grafos

- **2026-11-23** em [Grafos mais leves (LightRAG e HippoRAG)](rag/grafos-leves-lightrag-e-hipporag.md): O LightRAG 1.5.8 exige Python 3.11 ou superior (as imagens Docker, com Python 3.12, não são afetadas) e descontinua os armazenamentos `PGGraphStorage` (Apache AGE), `RedisKVStorage` e `RedisDocStatusStorage`, que continuam a funcionar com um aviso no arranque. Traz mudanças incompatíveis: mudar `LIGHTRAG_KV_STORAGE` depois do primeiro arranque é recusado sem `LIGHTRAG_CONFIG_STORAGE` definido; com `LIGHTRAG_API_KEY` definida e sem `WHITELIST_PATHS`, as rotas `/api/*` compatíveis com a Ollama respondem 403 sem chave; a WebUI pede início de sessão em vez de chave; os blocos de texto com menos de 64 tokens são recusados; as consultas falhadas na biblioteca levantam exceção em vez de devolver `None`; e sai o `POST /documents/clear_cache`. Fonte: [HKUDS/LightRAG: releases](https://github.com/HKUDS/LightRAG/releases). Confiança: alta. Adicionado a 2026-11-26.
